1. Modelo de Regresión con Naive Bayes

data <- read.csv("train.csv")
# Seleccionar variables de interés
data <- data %>%
  select(SalePrice, GrLivArea, OverallQual, GarageCars, YearBuilt)
# Dividir en entrenamiento (80%) y prueba (20%)
set.seed(42)  # Para reproducibilidad
trainIndex <- createDataPartition(data$SalePrice, p = 0.8, list = FALSE)
training_data <- data[trainIndex, ]
testing_data <- data[-trainIndex, ]
# Crear variable categórica basada en cuartiles
training_data$PriceCategory <- cut(training_data$SalePrice,
                                   breaks = quantile(training_data$SalePrice, probs = seq(0, 1, 0.25), na.rm = TRUE),
                                   labels = c("Bajo", "Medio-Bajo", "Medio-Alto", "Alto"),
                                   include.lowest = TRUE)
testing_data$PriceCategory <- cut(testing_data$SalePrice,
                                  breaks = quantile(training_data$SalePrice, probs = seq(0, 1, 0.25), na.rm = TRUE),
                                  labels = c("Bajo", "Medio-Bajo", "Medio-Alto", "Alto"),
                                  include.lowest = TRUE)
# Convertir a factor
training_data$PriceCategory <- as.factor(training_data$PriceCategory)
testing_data$PriceCategory <- as.factor(testing_data$PriceCategory)
training_data$SalePrice <- as.numeric(training_data$SalePrice)
testing_data$SalePrice <- as.numeric(testing_data$SalePrice)

# Discretizar variable para Naive Bayes de regresión
breaks <- seq(min(training_data$SalePrice), max(training_data$SalePrice), length.out = 10)
training_data$SalePriceBin <- cut(training_data$SalePrice, breaks = breaks)

# Registrar tiempo de inicio
start_time_nb <- Sys.time()

# Entrenar el modelo Naive Bayes para regresión
nb_model <- naiveBayes(SalePriceBin ~ GrLivArea + OverallQual + GarageCars + YearBuilt, 
                      data = training_data)

# Registrar tiempo final
end_time_nb <- Sys.time()
time_nb <- end_time_nb - start_time_nb

# Predecir probabilidades
nb_pred_prob <- predict(nb_model, testing_data, type = "raw")

# Calcular predicciones usando promedio ponderado
bin_centers <- sapply(levels(training_data$SalePriceBin), function(bin) {
  interval <- as.numeric(strsplit(gsub("\\(|\\]", "", bin), ",")[[1]])
  mean(interval)
})

nb_predictions <- apply(nb_pred_prob, 1, function(probs) {
  sum(probs * bin_centers)
})

# También calcular predicciones en conjunto de entrenamiento para análisis de sobreajuste
train_pred_prob <- predict(nb_model, training_data, type = "raw")
train_predictions_nb <- apply(train_pred_prob, 1, function(probs) {
  sum(probs * bin_centers)
})

2. Análisis del Modelo de Regresión con Naive Bayes

# Métricas en conjunto de prueba

Análisis de los resultados del modelo Naive Bayes:

El modelo de regresión basado en Naive Bayes muestra un RMSE de prueba de 6.624082^{4} y un R² de 0.1037544. Esto indica que el modelo tiene cierta capacidad predictiva, pero presenta algunas limitaciones. La diferencia entre RMSE de entrenamiento y prueba nos permite evaluar si existe sobreajuste.

El valor R² relativamente bajo sugiere que el modelo explica solo una parte limitada de la variabilidad en los precios de venta. Esto es esperable dado que Naive Bayes asume independencia entre características, lo cual no es necesariamente cierto para datos de precios de viviendas donde existe correlación entre características como tamaño y calidad.

En el gráfico de valores reales vs predichos podemos observar que, aunque hay cierta tendencia lineal, existe dispersión considerable alrededor de la línea ideal, lo que confirma las limitaciones del modelo para capturar completamente la relación entre las variables predictoras y el precio.

3. Comparación con modelos anteriores (Regresión Lineal y Árbol de Regresión)

# Crear modelo de regresión lineal
start_time_lm <- Sys.time()
lm_model <- lm(SalePrice ~ GrLivArea + OverallQual + GarageCars + YearBuilt, data = training_data)
end_time_lm <- Sys.time()
time_lm <- end_time_lm - start_time_lm

# Predicciones del modelo lineal
lm_predictions_test <- predict(lm_model, testing_data)
lm_predictions_train <- predict(lm_model, training_data)

# Crear modelo de árbol de regresión
start_time_tree <- Sys.time()
tree_model <- rpart(SalePrice ~ GrLivArea + OverallQual + GarageCars + YearBuilt, 
                   data = training_data, method = "anova")
end_time_tree <- Sys.time()
time_tree <- end_time_tree - start_time_tree

# Predicciones del árbol
tree_predictions_test <- predict(tree_model, testing_data)
tree_predictions_train <- predict(tree_model, training_data)

# Calcular métricas para regresión lineal
rmse_lm_test <- rmse(testing_data$SalePrice, lm_predictions_test)
mae_lm_test <- mae(testing_data$SalePrice, lm_predictions_test)
rmse_lm_train <- rmse(training_data$SalePrice, lm_predictions_train)
r2_lm_test <- 1 - sum((testing_data$SalePrice - lm_predictions_test)^2) / sst_test
r2_lm_train <- 1 - sum((training_data$SalePrice - lm_predictions_train)^2) / sst_train

# Calcular métricas para el árbol de regresión
rmse_tree_test <- rmse(testing_data$SalePrice, tree_predictions_test)
mae_tree_test <- mae(testing_data$SalePrice, tree_predictions_test)

r2_tree_test <- 1 - sum((testing_data$SalePrice - tree_predictions_test)^2) / sst_test

Comparación de modelos de regresión:

En la comparación de los modelos, observamos que la Regresión Lineal es el mejor modelo para predecir los precios de las viviendas, ya que presenta el menor RMSE en prueba (34,154.19) y el mayor R² en prueba (0.7617), lo que indica una mejor capacidad de ajuste a los datos. Por otro lado, el Árbol de Regresión tiene un RMSE de prueba de 40,175.54 y un R² de 0.6703, mostrando un desempeño inferior a la regresión lineal pero aún mejor que Naive Bayes. El modelo de Naive Bayes obtiene el peor desempeño con un RMSE de prueba de 66,240.82 y un R² de 0.1037, lo que indica que no logra captar bien la relación entre las variables y el precio. Sin embargo, en términos de sobreajuste, Naive Bayes es el modelo más estable, con una diferencia mínima entre el RMSE de entrenamiento y prueba (63.38), mientras que la regresión lineal presenta una diferencia negativa significativa (-6,858.85), lo que sugiere que su rendimiento puede variar dependiendo de los datos de prueba. En cuanto al tiempo de ejecución, todos los modelos son rápidos, con la regresión lineal siendo la más eficiente (0.0024 s), seguida de Naive Bayes (0.0031 s) y el árbol de regresión siendo el más lento (0.0069 s). En conclusión, la Regresión Lineal es el modelo más efectivo en predicción, mientras que Naive Bayes es el más estable en términos de generalización, pero con un desempeño muy limitado.
