El resumen del árbol muestra que las vaariables de importancia son la calidad de los acabados de la casa, el vecindario en el que se ubica y el área habitable sobre el nivel del suelo. El árbol de regresión primero evalúa la calidad de los detalles, si esta es mayor que 8 evalúa de nuevo la cantidad y luego evalúa la cantidad de área habitable para asignarle un precio. Si la calidad de los acabados es menor que 8, evalúa en que vecindario se ubica la vivienda, finalmente evalua el área habitable, de nuevo el vecindario.

arbol_3 <- rpart(SalePrice ~ ., data = train, control = rpart.control(maxdepth = 3))
arbol_8 <- rpart(SalePrice ~ ., data = train, control = rpart.control(maxdepth = 8))
arbol_16 <- rpart(SalePrice ~ ., data = train, control = rpart.control(maxdepth = 16))

# Función para calcular métricas de cada modelo
evaluar_arbol <- function(modelo, nombre) {
  pred <- predict(modelo, train)
  R2 <- 1 - sum((train$SalePrice - pred)^2) / sum((train$SalePrice - mean(train$SalePrice))^2)
  RMSE <- sqrt(mean((train$SalePrice - pred)^2))
  cat(nombre, "- R2:", R2, " RMSE:", RMSE, "\n")
}

# Evaluar cada árbol

## Interpretacion del Arbol

El árbol clasifica una casa en base a su precio (Alto, bajo o mediano). Para determinar eso evalua factores como la calidad de los acabados, el área habitable. La primera divisón se hace evaluando la calidad de los acabados de la casa en una escala del 1 al 10, si la calidad es mayor a 8, entonces se determinará la cantidad de área habitable y luego el vecindario en el que se ubica la vivienda, dependiendo de el resultado de estas evaluaciones la casa será calificada como cara o mediana. Si la calidad de los acabos es mayor a 8 se harán más evaluaciones en diferentes variables como el área habitable, el vecindario, etc para clasificar el precio de la casa.

# Evaluar diferentes profundidades del árbol, lo haremos hasta 10 de 2 en 2
profundidades <- c(2, 4, 6, 8, 10)
resultados <- data.frame(Profundidad = profundidades, R2 = numeric(length(profundidades)), RMSE = numeric(length(profundidades)))

for (i in seq_along(profundidades)) {
  modelo_temp <- rpart(SalePrice ~ ., data = training_data, control = rpart.control(maxdepth = profundidades[i]))
  predicciones <- predict(modelo_temp, training_data)
  
  SSE <- sum((training_data$SalePrice - predicciones)^2)
  SST <- sum((training_data$SalePrice - mean(training_data$SalePrice))^2)
  resultados$R2[i] <- 1 - (SSE / SST)
  resultados$RMSE[i] <- sqrt(mean((training_data$SalePrice - predicciones)^2))
}

# Cargar librerías necesarias
library(randomForest)

# Función para rellenar valores faltantes
impute_missing_values <- function(df) {
  for (col in colnames(df)) {
    if (is.numeric(df[[col]])) {
      df[[col]][is.na(df[[col]])] <- median(df[[col]], na.rm = TRUE)  # Rellenar con la mediana
    } else {
      df[[col]][is.na(df[[col]])] <- names(sort(table(df[[col]]), decreasing = TRUE))[1]  # Rellenar con la moda
    }
  }
  return(df)
}

# Rellenar valores faltantes
